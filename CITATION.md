# Citation

This repository is the real-time deployment companion to the research
project:

**"AE-GMM: A Hybrid, Interpretable Approach for Robust Network Intrusion Detection"**

It packages the trained M3 AE-GMM model (Autoencoder + Gaussian Mixture Model,
with two-level SHAP explainability) into a standalone desktop application for
live network monitoring, including MAS+Replay incremental adaptation to new
environments.
